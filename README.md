# Sentiment & Topic Analysis Web App

Мультистраничное Streamlit-приложение для анализа тональности текстов, тематического моделирования и аспектно-ориентированного анализа (ABSA) с поддержкой локальных и облачных моделей.

## Основные возможности

- **Простой анализ настроения**: классификация отзывов на "Положительное", "Нейтральное", "Негативное" с помощью модели `blanchefort/rubert-base-cased-sentiment`.
- **Тематическое моделирование**:
  - **BERTopic**: извлечение ключевых слов-тем из текста с предобученной моделью.
  - **LDA (sklearn)**: локальная LDA-модель, обученная на корпусе, содержащем отзывы о заведениях общественного питания.
- **Abstract-Based Sentiment Analysis (ABSA)**:
  - **GPT-4.1 mini** (OpenAI API): аспектно-ориентированный анализ по списку тем с few-shot промптами.
  - **DeepSeek R1**: альтернативная облачная модель через DeepSeek API.
- **Страница справки**: подробное описание всех используемых моделей, их плюсы и минусы.
- **Загрузка файлов**: поддерживается пакетная обработка CSV и Excel, скачивание результатов.
